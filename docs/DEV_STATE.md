## M3 implementation and verification

- `PagePipeline` composes compiled identity/margin/spread/layout processors. ## Global reader and resume accessory — 2026-10-12

- Paged mode accepts a downward pull starting near the top; continuous mode accepts a rightward swipe from the physical left edge. Toolbar collapse and Escape are alternatives.
