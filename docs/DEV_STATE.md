## M2 implementation

- App uses NavigationSplitView/NavigationStack, directory search/title sorting/pagination/declared remote search, manga cover/metadata/chapters/resume, basic paged/vertical reader and source-key progress.

A compiled Manhuagui observer captures the site's own chapter metadata and requires its normal reader image DOM before returning references.
